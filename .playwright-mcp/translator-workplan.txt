1. 프로젝트 개요
Slack, 브라우저 등 macOS 어디서든 텍스트를 복사한 뒤 단축키(⌘+Shift+T) 하나로 팝업 번역창을 띄우는 도구를 개발한다. Claude CLI를 번역 엔진으로 사용하여 별도 API 키 없이 동작한다.


2. 개발 목표
* 드래그-복사-번역 반복 작업을 단축키 한 번으로 단축
* Slack 플러그인 없이 어떤 앱에서도 동작
* API 키 불필요 — Claude CLI(claude -p) 사용
* 번역 결과를 팝업에서 바로 클립보드에 복사 가능
* macOS 로그인 시 백그라운드 자동 실행 지원

4. 기능 명세
4-1. 클립보드 감지
* pbpaste 명령어로 현재 클립보드 텍스트 읽기
* 빈 클립보드일 경우 번역 실행 안 함


4-2. 번역 실행
* claude -p "[프롬프트]" 명령어 subprocess로 호출
* 번역 대상 언어: 한국어 (TARGET_LANG 변수로 변경 가능)
* CLI 오류 시 팝업에 에러 메시지 표시


4-3. 팝업 UI
* tkinter 기반 다크 테마 팝업 창
* 원문(상단) + 번역결과(하단) 2단 구성
* 번역 중 로딩 팝업 표시 (별도 스레드)
* 📋 복사 버튼으로 번역 결과 클립보드 저장
* ESC 키 또는 ✕ 버튼으로 팝업 닫기


4-4. 전역 단축키
* pynput 라이브러리로 전역 키보드 리스너 등록
* 단축키: ⌘ + Shift + T
* 백그라운드 스레드에서 번역 실행 (UI 블로킹 방지)

7. 설치 및 실행
7-1. 사전 조건
* macOS (Monterey 이상 권장)
* Python 3.x 설치
* Claude Code CLI 설치 및 로그인 완료


7-2. 설치 명령어
pip3 install pynputpython3 translator.py


7-3. macOS 접근성 권한
처음 실행 시 macOS 접근성 권한 요청이 발생한다.
* 시스템 환경설정 → 개인정보 보호 및 보안 → 접근성
* 터미널(또는 Python) 항목에 체크 → 단축키 정상 동작
